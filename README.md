Alex Rivera — Student Portfolio Website

A modern, welcoming, and responsive personal portfolio website built for Alex Rivera, a Computer Science & Interactive Design student. Designed with a clean aesthetic, friendly typography, and interactive project case studies to help visitors and recruiters easily explore projects, skills, and achievements.

🔗 Live Demo: https://lavanyasaisri-max.github.io/Alex-Rivera/

✨ Key Features

Responsive & Accessible Layout: Mobile-first design featuring a sticky navigation bar, smooth section scrolling, and an interactive mobile drawer menu.

Dark & Light Mode Toggle: Automatic system theme detection with manual toggle support persisted via localStorage.

Interactive Project Showcase: Filter projects dynamically by category (All, Web Dev, UI/UX, Data/AI) and open detailed Case Study Modals outlining the problem, technical architecture, and key impact.

Categorized Technical Toolkit: Structured overview of programming languages (with proficiency indicators), web/design frameworks, and developer collaboration tools.

Achievements & Leadership Timeline: Highlights hackathon awards, campus leadership roles, academic honors, and certifications.

Interactive Contact Section: Includes client-side form validation with instant confirmation feedback, social profile links, and a one-click email copy button.

🛠️ Built With

HTML5 — Semantic structure and ARIA accessibility attributes

Tailwind CSS (CDN) — Utility-first styling, custom color palette, and responsive grid layouts

Vanilla JavaScript (ES6+) — Dynamic project filtering, modal state management, theme persistence, and form validation

Font Awesome & Google Fonts — Crisp iconography paired with Plus Jakarta Sans and Inter typography

🚀 Getting Started

Because this portfolio is built as a self-contained single-page application with zero build-step dependencies, you can run it locally in seconds:

Clone the repository:

git clone https://github.com/lavanyasaisri-max/Alex-Rivera.git


Navigate into the project folder:

cd Alex-Rivera


Open in your browser:
Double-click index.html or launch it using a local development server (such as the VS Code Live Server extension).

Alex-Rivera/

🎨 Customization Guide

To personalize this template for your own portfolio:

Profile & Bio: Update the hero headline, university details, and custom SVG avatar inside the #about section of index.html.

Projects: Edit the projectsData array inside the <script> tag to add your own project titles, descriptions, tech tags, and demo/GitHub links.

Contact Info: Replace the email address (#email-text) and social links in the #contact section.
